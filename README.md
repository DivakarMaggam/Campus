# Campus Lost and Found Recovery Portal
A web-based application for students and staff to **report, search, and recover lost and found items** on campus.
# Features
* Report lost/found items
* Search items
* Add, update, and delete records
* Centralized database
* Simple and user-friendly interface
# Technologies
* Java
* Spring Boot
* HTML, CSS
* MySQL
* Thymeleaf
# Objective
To provide a simple and organized digital solution for managing campus lost-and-found items.
